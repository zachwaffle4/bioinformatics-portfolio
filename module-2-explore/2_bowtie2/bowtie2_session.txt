# Peek at the first lines of the genome and the two read files
$ head lambda_virus.fa
$ head reads_1.fq
$ head reads_2.fq
# (re-run Oct 18, trimmed) the genome header is ">gi|9626243|ref|NC_001416.1| Enterobacteria phage lambda, complete genome";
# the reads are FASTQ with names like "@r1", one 4-line record per read, with Ns at a few low-quality positions.

# Length of the genome: count the characters on the sequence lines, ignoring the header line and newlines
$ grep -v ">" lambda_virus.fa | tr -d "\n" | wc -c
48502

# Number of reads in each FASTQ file: every read takes 4 lines, so reads = lines / 4
$ wc -l reads_1.fq reads_2.fq
  40000 reads_1.fq
  40000 reads_2.fq
  80000 total
# 40000 / 4 = 10,000 reads in each file (re-run Oct 18)

# Build the bowtie2 index (six lambda_virus*.bt2 files) from the genome, one level below lambda_virus.fa in index/
$ cd index
$ bowtie2-build ../lambda_virus.fa lambda_virus

# Align reads_1.fq as unpaired reads (-U) to the index and write SAM to eg1.sam
$ bowtie2 -x lambda_virus -U ../reads_1.fq -S eg1.sam

# Align both files as paired-end reads (-1/-2) and write SAM to eg2.sam
$ bowtie2 -x lambda_virus -1 ../reads_1.fq -2 ../reads_2.fq -S eg2.sam

# ---------------------------------------------------------------------------
# Second pass: actual variant calling
# ---------------------------------------------------------------------------
# The tutorial's command stops at mpileup, so the eg2.raw.bcf and variants.txt above hold one pileup record per
# genome position (~48,500 records for the 48,502 bp genome), not variant calls. Found the missing step by web
# search: pipe mpileup into `bcftools call`. This overwrote eg2.raw.bcf and variants.txt.

# Pile up eg2.sorted.bam against the reference, then call variants (-m = multiallelic caller, -v = keep variant
# sites only) and write compressed BCF (-Ob) to eg2.raw.bcf.
# The "diploid" note is only a default-ploidy warning; lambda phage is haploid, so every call shows as 1/1.
[harel.z@c0649]/courses/BIOL2406.202710/students/harel.z/inclass/bowtie/index% bcftools mpileup -f ../lambda_virus.fa eg2.sorted.bam | bcftools call -mv -Ob -o eg2.raw.bcf
Note: none of --samples-file, --ploidy or --ploidy-file given, assuming all sites are diploid
[mpileup] 1 samples in 1 input files
[mpileup] maximum number of reads per input file set to -d 250

# Convert the binary BCF to VCF text in variants.txt (now 90 variant records)
[harel.z@c0649]/courses/BIOL2406.202710/students/harel.z/inclass/bowtie/index% bcftools view eg2.raw.bcf > variants.txt

# View variants.txt in vim
[harel.z@c0649]/courses/BIOL2406.202710/students/harel.z/inclass/bowtie/index% vim variants.txt
