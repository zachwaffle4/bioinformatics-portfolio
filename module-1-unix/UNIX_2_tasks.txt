# 1. tr '\n' '@' < intron_IME_data.fasta
#    Reads the file (< redirects it in) and replaces every newline with @, so the
#    whole file becomes one long line. That lets later steps treat a header and
#    its multi-line sequence as a single unit.
# 2. sed 's/>/#>/g'
#    Puts a # in front of every > (the start of each FASTA header). The g makes
#    it replace every match on the line, not just the first.
# 3. tr '#' '\n'
#    Turns each # into a newline, so every record (header + sequence, with @
#    where its newlines used to be) is now on its own line.
# 4. grep "i1_.*5UTR"
#    Keeps only records whose header has i1_ (first intron) followed later by
#    5UTR (the intron is in the 5' UTR).
# 5. sort -nk 3 -t "_"
#    -t "_" splits each line into fields at underscores, -k 3 sorts on the 3rd
#    field (the distance from the transcription start site), and -n sorts it as
#    a number, so the closest introns come first.
# 6. head -n 5
#    Keeps the first five records: the five first introns in the 5' UTR that are
#    closest to the TSS (7, 7, 14, 18 and 19 bases away).
# 7. tr '@' '\n'
#    Turns the @s back into newlines, so the output is normal FASTA again.
